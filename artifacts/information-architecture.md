# Information Architecture: Trading Agent (AI-советник)

> **Версия:** 1.0
> **Дата:** 2026-03-14
> **Основано на:** Brief, USM v1.1, C4 v1.0, API Inventory v1.0

---

## 1. Пользователи и их цели

### Основные роли

| Роль | Главная цель | Частота использования |
|------|--------------|----------------------|
| Трейдер | Получить обоснованную рекомендацию по сделке и быстро её исполнить | Ежедневно, несколько раз в течение торговой сессии |
| Администратор (разработчик) | Убедиться, что система работает корректно и модель не деградирует | Ежедневно, 1-2 раза |

### Mental Model

- **Трейдер:** воспринимает систему как персонального аналитика — спрашиваешь «что по SBER?», получаешь краткий ответ с цифрами в чате, а для детального анализа открываешь график в мини-приложении. Два режима: «быстро в чате» и «детально на графике»
- **Администратор:** воспринимает как дашборд здоровья системы — зашёл, увидел зелёные индикаторы, ушёл. Если красное — drill-down

## 2. Карта интерфейсов

Система состоит из **трёх отдельных интерфейсов**, каждый со своей навигацией:

```
Trading Agent
│
├── 💬 Telegram Bot (чат-интерфейс)
│   ├── /start — онбординг
│   ├── Выбор тикеров (inline-кнопки)
│   ├── Описание стратегии (свободный текст)
│   ├── Подтверждение профиля
│   ├── «Анализ TICKER» — быстрая аналитика
│   ├── Настройка уведомлений
│   └── Push-уведомления (входящие алерты)
│
├── 📊 Mini App (визуальный интерфейс трейдера)
│   ├── Вкладки тикеров сверху (SBER | GAZP | LKOH | ... | [+])
│   │   ├── 📈 График (свечи + overlay)
│   │   │   ├── Свечной график (OHLCV)
│   │   │   ├── Стоп-лосс / тейк-профит (линии)
│   │   │   ├── Прогноз модели (пунктир + интервал)
│   │   │   └── Переключатель таймфреймов (15м | 30м | 1ч)
│   │   ├── 🔘 Панель иконок-кнопок (сбоку или снизу от графика)
│   │   │   ├── 📋 Карточка тикера → модалка (досье)
│   │   │   │   ├── Текущая цена, прогноз
│   │   │   │   ├── Технические показатели (15 переменных модели)
│   │   │   │   ├── Классификация (голубая фишка / нет)
│   │   │   │   ├── Корреляция с MOEX (Spearman)
│   │   │   │   └── Последние новости
│   │   │   ├── 📊 Sentiment → модалка (детали)
│   │   │   │   ├── Шкала (позитив / негатив)
│   │   │   │   ├── Коэффициент sentiment
│   │   │   │   ├── Динамика (тренд)
│   │   │   │   └── Последние данные (источники, посты)
│   │   │   └── 🔗 «Открыть в терминале» → deep link в Т-Банк
│   │   └── Компактные виджеты sentiment и сигнала рядом с графиком
│   └── ⚙️ Настройки (тикеры [+/-], уведомления)
│
└── 🛠️ Админ-панель (веб-интерфейс)
    ├── 📊 Дашборд (обзор)
    │   ├── Статус pipeline'ов (светофор)
    │   ├── DAU / активные пользователи
    │   └── Сводка метрик модели
    ├── 👥 Пользователи
    │   ├── Таблица: ID, username, тикеры, last_active
    │   └── Фильтрация по активности
    ├── 📈 Метрики модели
    │   ├── MAPE по тикерам (таблица + тренд)
    │   ├── Win rate по тикерам
    │   ├── Время inference (среднее, p95)
    │   └── Drill-down по тикеру (тренд за 30 дней)
    └── 🔧 Pipeline'ы
        ├── Статус: data_collector, sentiment, ml_engine
        ├── Последний успех / сбой
        └── Текст последней ошибки
```

### Описание разделов

| Раздел | Назначение | Доступ |
|--------|-----------|--------|
| Telegram Bot | Быстрое взаимодействие: онбординг, команды, уведомления | Все (через /start) |
| Mini App — График | Визуальный анализ тикера с overlay аналитики | Авторизованные (через Telegram WebApp) |
| Mini App — Карточка тикера | Полное досье по инструменту за секунды | Авторизованные |
| Mini App — Sentiment | Настроение рынка по данным из Т-Пульс и новостей | Авторизованные |
| Mini App — Настройки | Управление тикерами и уведомлениями | Авторизованные |
| Админ-панель — Дашборд | Обзор здоровья системы | Администратор |
| Админ-панель — Пользователи | Статистика использования | Администратор |
| Админ-панель — Метрики | Качество модели и деградация | Администратор |
| Админ-панель — Pipeline'ы | Статус источников данных | Администратор |

## 3. Навигация

### Telegram Bot — навигация через команды и кнопки

| Элемент | Тип | Куда ведёт | Приоритет |
|---------|-----|-----------|-----------|
| /start | Команда | Онбординг (приветствие + выбор тикеров) | Высокий |
| «Анализ TICKER» | Текстовая команда | Краткая аналитика в чате | Высокий |
| [Открыть график 📊] | Inline-кнопка (в сообщении) | Mini App на вкладке тикера | Высокий |
| Выбор тикеров | Inline-кнопки | Добавление/удаление тикеров | Средний |
| Настройки уведомлений | Inline-кнопки | Конфигурация триггеров | Средний |

**Паттерн навигации:** линейный диалог (бот ведёт пользователя) + команды для прямого доступа. Бот отвечает на свободный текст (название тикера) и на кнопки.

### Mini App — навигация через вкладки + панель иконок

| Позиция | Элемент | Куда ведёт | Приоритет |
|---------|---------|-----------|-----------|
| Верх | Вкладки тикеров (SBER \| GAZP \| ... \| [+]) | Переключение между тикерами | Высокий |
| Под графиком | Переключатель таймфреймов (15м \| 30м \| 1ч) | Смена таймфрейма графика | Высокий |
| Сбоку / снизу от графика | Панель иконок-кнопок | Открытие модалок с деталями | Высокий |
| Иконка 📋 | Карточка тикера | Модалка: досье тикера | Средний |
| Иконка 📊 | Sentiment | Модалка: коэффициент, тренд, источники | Средний |
| Иконка 🔗 | «Открыть в терминале» | Deep link → Т-Банк | Средний |
| Рядом с графиком | Компактные виджеты (sentiment, сигнал) | По тапу → соответствующая модалка | Средний |
| Вкладка [+] | Добавить тикер | Выбор из справочника | Средний |

**Паттерн навигации:** вкладки сверху для тикеров, график занимает основную площадь экрана. Детали (карточка, sentiment, новости) открываются в модальных окнах по нажатию иконок — график всегда остаётся на виду. Компактные виджеты рядом с графиком показывают ключевые цифры (sentiment-скор, текущий сигнал) без необходимости открывать модалку.

### Админ-панель — навигация через sidebar

| Позиция | Элемент | Куда ведёт | Приоритет |
|---------|---------|-----------|-----------|
| Sidebar 1 | Дашборд | Обзор системы | Высокий |
| Sidebar 2 | Пользователи | Таблица пользователей | Средний |
| Sidebar 3 | Метрики модели | MAPE, win rate по тикерам | Высокий |
| Sidebar 4 | Pipeline'ы | Статус data pipeline'ов | Высокий |

**Паттерн навигации:** sidebar + основная область контента. Drill-down по клику на строку таблицы.

### Утилитарная навигация

- **Поиск:** нет (MVP — до 5 тикеров, справочник маленький)
- **Уведомления:** push в Telegram-чат (не в Mini App)
- **Помощь:** /help команда в боте
- **Язык:** русский (английский — v2.0)

## 4. Ключевые User Flows

### Flow 1: Онбординг (первый запуск)

```
/start в Telegram
    → Приветствие бота
    → Выбор тикеров (inline-кнопки)
    → Описание стратегии (свободный текст)
    → Бот формализует профиль (через LLM)
    → Подтверждение профиля [Да] / [Изменить]
    → «Готово! Открой мини-приложение 📊»
```

**Детали:**
1. Точка входа: команда /start в Telegram
2. Бот ведёт диалог пошагово, каждый шаг — одно сообщение
3. Выбор тикеров — через inline-кнопки (мультивыбор)
4. Стратегия — свободный текст, бот формализует и показывает результат
5. Весь процесс ≤ 2 минут
6. Результат: пользователь готов получать рекомендации

### Flow 2: Быстрый анализ в чате

```
Трейдер пишет «Анализ SBER»
    → Бот запрашивает данные (кэш или генерация)
    → Ответ в чате: направление, цена, стоп, тейк, sentiment, объяснение
    → [Открыть график] — кнопка для перехода в Mini App
```

**Детали:**
1. Точка входа: текстовая команда в чате
2. Ответ за секунды (из кэша) или до 15с (генерация)
3. Формат: структурированное сообщение с эмодзи-маркерами
4. Результат: трейдер получает цифры, может перейти к графику

### Flow 3: Визуальный анализ в Mini App

```
Трейдер открывает Mini App (из кнопки в чате или напрямую)
    → Загрузка: 4 параллельных запроса (OHLCV, сигнал, sentiment, прогноз)
    → Отображение: свечной график + overlay (стоп/тейк, прогноз, sentiment)
    → Трейдер переключает таймфрейм или тикер
    → Трейдер открывает карточку тикера (досье)
    → [Открыть в терминале] → deep link в Т-Банк
    → Трейдер совершает сделку в терминале брокера
```

**Детали:**
1. Точка входа: кнопка Mini App в Telegram
2. Данные загружаются параллельно для минимизации ожидания
3. Переключение тикеров — перезагрузка данных для нового тикера
4. Переход в терминал — в один тап
5. Результат: трейдер принял решение и совершил сделку

### Flow 4: Push-уведомление

```
Система обнаруживает триггер (резкое изменение sentiment)
    → Проверка: у кого включены уведомления по этому тикеру
    → Push в Telegram: «⚠️ SBER: sentiment упал на 40%...»
    → Трейдер видит уведомление
    → [Открыть график] → Mini App
```

**Детали:**
1. Точка входа: автоматический триггер системы
2. Уведомление содержит ключевые цифры + причину
3. Кнопка для перехода в мини-приложение
4. Результат: трейдер не пропустил важное событие

### Flow 5: Мониторинг системы (админ)

```
Админ открывает админ-панель
    → Дашборд: статусы pipeline'ов + сводка метрик
    → Если статус красный → drill-down в Pipeline'ы
    → Если MAPE растёт → drill-down в Метрики → тикер → тренд за 30 дней
```

**Детали:**
1. Точка входа: URL админ-панели (веб)
2. Дашборд загружает данные параллельно
3. Drill-down по клику на проблемную метрику
4. Результат: админ понимает состояние системы

## 5. Иерархия контента

### Приоритеты отображения

| Приоритет | Контент | Почему важен |
|-----------|---------|-------------|
| P1 (Критический) | Сигнал: направление, цена входа, стоп, тейк | Без этого нельзя принять решение по сделке |
| P1 (Критический) | Свечной график с overlay | Визуальное подтверждение сигнала |
| P1 (Критический) | Объяснение сигнала | Без «почему» — нет доверия (insight от Дмитрия) |
| P2 (Важный) | Sentiment-индикатор | Контекст для решения, уникальная фича |
| P2 (Важный) | Карточка тикера (досье) | Быстрый вход в контекст по незнакомому инструменту |
| P2 (Важный) | Прогноз модели на графике | Визуализация ожидаемого движения |
| P3 (Вспомогательный) | Технические показатели (15 переменных) | Для опытных трейдеров, можно скрыть |
| P3 (Вспомогательный) | Корреляция с MOEX | Дополнительная информация |
| P3 (Вспомогательный) | Настройки уведомлений | Настраивается один раз |

### Группировка контента

- **Telegram Bot:** по типу взаимодействия (команда → ответ). Хронологическая лента
- **Mini App:** по тикерам (вкладки). Внутри тикера — график на весь экран + панель иконок для доступа к деталям через модалки
- **Админ-панель:** по функциональным разделам (sidebar). Внутри — таблицы с drill-down

## 6. Поиск и обнаружение

### Поиск

- **Тип:** нет глобального поиска на MVP
- **Почему:** максимум 5 тикеров на пользователя, справочник ≤ 15 голубых фишек — поиск не нужен, достаточно списка
- **[💡 Предложение]** Поиск тикеров — при расширении до второго эшелона (v2.0)

### Обнаружение контента

- **Рекомендации:** сигналы приходят проактивно через push-уведомления
- **Связанные элементы:** из сигнала в чате → график в Mini App (кнопка)
- **Популярное/Недавнее:** нет на MVP. Сводка «что произошло с тикерами» — v1.1 (US-020)

## 7. Состояния страниц

### Пустые состояния

| Экран | Когда пусто | Что показываем |
|-------|-------------|----------------|
| Mini App — нет тикеров | Пользователь не выбрал тикеры | «Добавь тикеры кнопкой [+] или через бота: /start» |
| Mini App — нет сигнала | Сигнал ещё не сгенерирован | График без overlay, текст «Сигнал в процессе генерации...» |
| Mini App — карточка тикера | Данные загружаются | Скелетон карточки |
| Админ — пользователи | Нет пользователей | «Пока нет зарегистрированных пользователей» |
| Админ — метрики | Модель ещё не генерировала сигналы | «Данные появятся после первой генерации сигналов» |

### Состояния загрузки

- **Mini App — первая загрузка:** скелетон графика + спиннер данных
- **Mini App — смена тикера:** спиннер поверх графика, данные перезагружаются
- **Админ-панель:** скелетон таблиц

### Ошибки

- **Нет сети (Mini App):** «Нет подключения. Проверь интернет и попробуй снова» + кнопка «Обновить»
- **Данные устарели:** «Данные от [время]. Обновить?» — мягкое предупреждение
- **Сбой pipeline (Админ):** красный индикатор + текст ошибки + время последнего успеха
- **Бот не отвечает:** Telegram сам показывает «typing...» / таймаут

## 8. Адаптация под устройства

### Приоритеты платформ

| Платформа | Приоритет | Особенности |
|-----------|-----------|------------|
| Mobile (Telegram) | **Основная** | Mini App работает в WebView Telegram. Оптимизация под вертикальный экран |
| Desktop (Telegram) | Вторичная | Mini App также открывается, но в десктопном Telegram. График может быть шире |
| Desktop (браузер) | Только админ-панель | Админ-панель — полноценный веб-интерфейс |

### Адаптация навигации

- **Mini App (mobile):** вкладки тикеров сверху (горизонтальный скролл), контент вертикально. Одна колонка
- **Mini App (desktop Telegram):** тот же layout, но шире — график занимает больше места
- **Админ-панель (desktop):** sidebar слева + основная область. Таблицы с горизонтальным скроллом при необходимости
