# User Story Map: Trading Agent (AI-советник)

> Дата: 2026-03-11
> Версия: 1.1
> Источники: Lean Canvas v1.0, Persona Interview (Дмитрий, Артём), Pitch & QA v2.0

## Backbone

### Путь трейдера (основной)
Онбординг → Исследование тикера → Получение рекомендаций → Анализ на графике → Торговля → Отслеживание результатов

### Путь администратора
Мониторинг пользователей → Мониторинг модели → Мониторинг pipeline'ов → Управление переобучением

## Release 1.0 (MVP)

### [EPIC-001] Онбординг и настройка
---
**[US-001][Трейдер] Как трейдер, я хочу подключить бота через /start, чтобы начать работу за минимальное количество шагов.**
- [ ] Бот приветствует и кратко объясняет, что он умеет
- [ ] Пользователь может перейти к выбору тикеров сразу из чата или из мини-приложения
- [ ] Онбординг занимает не более 2 минут
- Notes: Минимум трения на старте — трейдеры не дают вторых шансов (insight из интервью с Дмитрием)
---
**[US-002][Трейдер] Как трейдер, я хочу выбрать тикеры, за которыми буду следить, чтобы получать релевантные рекомендации.**
- [ ] Список доступных тикеров (голубые фишки MOEX на старте)
- [ ] Возможность выбрать несколько тикеров
- [ ] Возможность добавить/убрать тикер позже
- [ ] Выбор доступен и в чате, и в мини-приложении
- Notes: На MVP — голубые фишки. Второй эшелон — v2.0
---
**[US-003][Трейдер] Как трейдер, я хочу описать свою стратегию торговли в свободной форме, чтобы агент учитывал мой стиль при рекомендациях.**
- [ ] Пользователь описывает стратегию текстом в чате
- [ ] Система преобразует описание в структурированный профиль стратегии
- [ ] Пользователь подтверждает или корректирует профиль
- [ ] Профиль можно изменить позже
- Notes: [⚠️ Risk] Требуется custdev с трейдерами — что именно входит в описание стратегии (таймфреймы, допустимый риск, стиль). Пока открытый вопрос
---
**[US-004][Трейдер] Как трейдер, я хочу настроить уведомления, чтобы получать алерты только по важным событиям, а не спам.**
- [ ] Выбор типов триггеров: резкое изменение sentiment, подход к уровню, важная новость
- [ ] Выбор периодичности (раз в час / по событию / вручную по кнопке)
- [ ] Возможность отключить уведомления
- Notes: «Не спамьте, но не пропустите важное» — Артём
---

### [EPIC-002] Исследование тикера
---
**[US-005][Трейдер] Как трейдер, я хочу открыть карточку (досье) тикера, чтобы за секунды получить полную картину по незнакомому инструменту.**
- [ ] Карточка содержит: текущая цена, прогноз модели, sentiment, последние важные новости, волатильность, ключевые уровни
- [ ] Карточка доступна по тапу на тикер в мини-приложении
- [ ] Информация обновляется в реальном времени или по запросу
- Notes: Killer feature для новичков. Экономит 30 мин ручного сбора (insight от Артёма)
---
**[US-006][Трейдер] Как трейдер, я хочу видеть текущий sentiment по тикеру, чтобы понимать настроение рынка перед входом в сделку.**
- [ ] Sentiment отображается как индикатор (шкала позитив/негатив)
- [ ] Источники: Т-Пульс, новостные каналы
- [ ] Видна динамика sentiment (рос/падал за последний час/день)
- Notes: Уникальная фича — этого нет у конкурентов в удобном виде
---
**[SS-001][Система] Как система, я хочу агрегировать новости и посты из Т-Пульса по выбранным тикерам, чтобы пользователь видел актуальный sentiment.**
- [ ] Парсинг новостных Telegram-каналов (Headlines и др.)
- [ ] Парсинг Т-Пульса по тикеру
- [ ] Семантический анализ: фильтрация шума, выделение sentiment
- [ ] Обновление данных с заданной периодичностью
- Notes: Мемы и эмоции тоже сигнал — массовая паника коррелирует с разворотами
---

### [EPIC-003] Генерация рекомендаций
---
**[US-007][Трейдер] Как трейдер, я хочу получать сигналы на вход/выход из сделки, чтобы не пропускать возможности и вовремя фиксировать результат.**
- [ ] Сигнал содержит: направление (buy/sell), рекомендуемую цену входа
- [ ] Сигнал приходит в чат с ключевыми цифрами
- [ ] Сигнал учитывает таймфрейм пользователя
- Notes: Главная боль обоих персон
---
**[US-008][Трейдер] Как трейдер, я хочу получать рекомендации по стоп-лоссу и тейк-профиту, чтобы не ставить их «на глаз».**
- [ ] Конкретные ценовые уровни стоп-лосса и тейк-профита
- [ ] Уровни рассчитаны на основе модели и текущей волатильности
- [ ] Визуальное отображение на графике
- Notes: «Я ставлю стопы наугад — это главная проблема» — Артём
---
**[US-009][Трейдер] Как трейдер, я хочу видеть объяснение к каждому сигналу, чтобы понимать логику и принимать осознанное решение.**
- [ ] К каждому сигналу — текстовое объяснение: какие факторы повлияли (sentiment, теханализ, новость)
- [ ] Объяснение краткое (2-3 предложения), но содержательное
- [ ] Формат: «Рекомендация основана на: снижение sentiment на X%, пробой уровня Y, новость Z»
- Notes: Объяснимость важнее точности (insight от Дмитрия). Без «почему» это очередной канал с сигналами
---
**[SS-002][Система] Как система, я хочу рассчитывать прогноз цены на основе модели и экзогенных факторов, чтобы генерировать обоснованные рекомендации.**
- [ ] Модель использует исторические OHLCV + технические индикаторы
- [ ] Модель учитывает sentiment и новостной фон
- [ ] Прогноз включает доверительный интервал
- [ ] Метрика качества: MAPE
- Notes: Развитие ARMAExo из ноутбука + новые экзогенные факторы

### [EPIC-004] Визуализация на графике (мини-приложение)
---
**[US-010][Трейдер] Как трейдер, я хочу открыть мини-приложение в Telegram и увидеть график тикера с аналитикой, чтобы принять решение визуально.**
- [ ] Интерактивный график с японскими свечами
- [ ] Переключение между тикерами через вкладки
- [ ] Переключение между таймфреймами (15м, 30м, 1ч)
- Notes: Канвас с вкладками — идея пользователя
---
**[US-011][Трейдер] Как трейдер, я хочу видеть уровни стоп-лосса и тейк-профита прямо на графике, чтобы оценить соотношение риск/прибыль визуально.**
- [ ] Горизонтальные линии стоп-лосса (красная) и тейк-профита (зелёная) на графике
- [ ] Подписи с ценовыми уровнями
- [ ] Обновление при смене рекомендации
---
**[US-012][Трейдер] Как трейдер, я хочу видеть sentiment-индикатор рядом с графиком, чтобы одним взглядом оценить настроение рынка.**
- [ ] Шкала или полоска: зелёное — позитив, красное — негатив
- [ ] Расположена рядом с графиком, не перекрывает данные
- [ ] Обновляется в реальном времени или по запросу
- Notes: «Одним взглядом — панике или эйфория» — Артём
---
**[US-013][Трейдер] Как трейдер, я хочу видеть прогноз модели на графике, чтобы понимать ожидаемое направление цены.**
- [ ] Линия прогноза (пунктирная) с доверительным интервалом (заливка)
- [ ] Точки прогноза на нескольких фреймах вперёд
- [ ] Визуально отличается от исторических данных
- Notes: Как на графике из ноутбука — оранжевая линия + жёлтый интервал

## Gap Analysis & Risks

### Пропущенные функции (из анализа аналогов)

- **Risk management dashboard** — общий P&L по всем рекомендациям, просадка портфеля. Может быть полезен для v1.1+
- **Бэктест-модуль для пользователя** — возможность прогнать модель на исторических данных самому. Для конкурса ITMO может быть selling point
- **Социальные функции** — шаринг сигналов между пользователями, рейтинг. Для роста, но не для MVP
- **Мультиброкер** — поддержка БКС, Финам и др. Пока только Т-Банк

### Открытые вопросы

| ID | Вопрос | Как закрыть |
|----|--------|-------------|
| OQ-001 | Что именно входит в «профиль стратегии» трейдера (US-003)? | Custdev с реальными трейдерами |
| OQ-002 | Можно ли передать данные (тикер, направление) при редиректе в терминал Т-Банка? | Исследование T-Bank API |
| OQ-003 | Как часто обновлять sentiment — реальное время или с задержкой? | Зависит от нагрузки на сервер и доступности API |
| OQ-004 | Модель монетизации — подписка, freemium, % от прибыли? | A/B тестирование, custdev (гипотеза H-001) |
| OQ-005 | Скорость генерации сигнала на 15м таймфрейме — достаточна ли? | Техническое прототипирование |

### Риски

- [⚠️ Risk] **Точность модели на коротких таймфреймах** — ARMAExo тестировалась на дневных данных, интрадей (15м) может вести себя иначе. Критично для доверия пользователей
- [⚠️ Risk] **Парсинг Т-Пульса** — возможны ограничения API / блокировки при парсинге. Нужен fallback
- [⚠️ Risk] **Первая неделя определяет retention** — если первые сигналы неточные, пользователь уйдёт (insight от Дмитрия)
- [⚠️ Risk] **Регуляторные ограничения** — предоставление инвестиционных рекомендаций может требовать лицензии. Дисклеймер обязателен
