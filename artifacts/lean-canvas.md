# Lean Canvas: Trading Agent (AI-советник)

> Дата создания: 2026-03-11
> Версия: 1.0

---

## 1. Problem (Проблема)

### Топ-3 проблемы:
1. **Ручной мониторинг отнимает слишком много времени** — интрадей-трейдер вынужден постоянно наблюдать за графиками, новостями и соцсетями, что выматывает и снижает качество решений
2. **Неуверенность в сигналах и объёмах** — когда входить, сколько брать, на каком этапе фиксировать — приходится полагаться на интуицию, особенно при малом опыте
3. **Высокий порог входа в новые тикеры** — нет быстрого способа собрать и агрегировать всю информацию по незнакомому инструменту (история, новости, sentiment, корпоративные события)

### Existing Alternatives (как решают сейчас):
- Ручной анализ графиков в терминале брокера / TradingView
- Мониторинг новостных каналов и Т-Пульса вручную
- Telegram-каналы с торговыми сигналами (без персонализации, без объяснений)
- Интуиция и опыт

---

## 2. Customer Segments (Сегменты клиентов)

### Целевой сегмент:
- **Кто:** интрадей-трейдеры Московской биржи, работающие на коротких таймфреймах (15м, 30м, 1ч)
- **Характеристики:** активные трейдеры с разным уровнем опыта, торгуют акциями (голубые фишки и второй эшелон), ценят время и хотят снизить когнитивную нагрузку

### Early Adopters (кто купит первым):
- Знакомые трейдеры (прямой доступ, уже есть потребность)
- Трейдеры-новички, которым не хватает опыта для уверенных решений
- Активные пользователи Т-Пульса, открытые к AI-инструментам

---

## 3. Unique Value Proposition (UVP)

### Главное обещание:
> AI-советник, который объединяет технический анализ, новостной фон и sentiment соцсетей в одну конкретную рекомендацию — прямо на графике тикера

### High-Level Concept:
> "AI-копилот для интрадей-трейдера" — агент, который смотрит за рынком за тебя и подсказывает, что делать

---

## 4. Solution (Решение)

### Топ-3 функции:
1. **Генерация торговых сигналов** — рекомендации по входу/выходу с конкретными уровнями стоп-лосса и тейк-профита
2. **Визуализация аналитики на графике** — мини-приложение в Telegram, где вся аналитика рисуется поверх графика тикера (уровни, зоны, сигналы)
3. **Агрегация информации по тикеру** — сбор и анализ новостей, sentiment соцсетей (Т-Пульс), технических индикаторов и макроданных в единую картину

### MVP Scope:
- [ ] Модель прогнозирования на основе OHLCV + экзогенные факторы (развитие ARMAExo)
- [ ] Интеграция с T-Bank API (получение данных, sandbox-торговля)
- [ ] Сбор и семантический анализ новостного фона и Т-Пульса
- [ ] Telegram-бот с мини-приложением (графики + overlay аналитики)
- [ ] Рекомендации: сигналы, стоп-лоссы, тейк-профиты

## 5. Channels (Каналы)

### Как найдём первых клиентов:
- Прямой доступ к знакомым трейдерам (early adopters + обратная связь)
- Конкурс ITMO Junior ML Contest 2026 (витрина проекта)

### Основные каналы привлечения:
- Т-Пульс (органическое присутствие в среде трейдеров)
- Соцсети и трейдерские группы / чаты в Telegram
- Сарафанное радио через знакомых
- Другие конкурсные и образовательные площадки

## 7. Cost Structure (Структура затрат)

### Основные статьи расходов:
- **Разработка:** solo-разработчик (собственное время)
- **Инфраструктура:** домашний сервер (уже есть), бесплатный Mistral API
- **Данные:** T-Bank API (бесплатный), возможно платные источники новостей/sentiment
- **Маркетинг:** минимальный бюджет (органические каналы)

### Burn rate:
- Около 0₽/мес на старте (собственные ресурсы), возможно небольшие расходы на API или данные

---

## 8. Key Metrics (Ключевые метрики)

### North Star Metric:
> Точность торговых сигналов (% прибыльных рекомендаций)

### Дополнительные метрики:
- **Качество модели:** MAPE (Mean Absolute Percentage Error) — целевая метрика прогнозирования
- **Направленная точность:** % верно предсказанных направлений (вверх/вниз)
- **Retention:** DAU/MAU — возвращаются ли трейдеры каждый день
- **Activation:** % пользователей, совершивших сделку по рекомендации

---

## 9. Unfair Advantage (Некопируемое преимущество)

### Что нельзя скопировать:
- Собственная прогнозная модель (ARMAExo + развитие с учётом экзогенных факторов)
- UX мини-приложения: аналитика рисуется прямо на графике — пользователь только фиксирует
- Потенциально: автоматическое выставление стопов / тейк-профитов через API брокера

### План усиления:
- Накопление уникального датасета (sentiment + результаты сделок)
- Обратная связь от трейдеров → улучшение модели
- Экспертиза знакомых-трейдеров как доменное знание
